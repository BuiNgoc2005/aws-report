* Hiểu được các dịch vụ lưu trữ trên AWS và mục đích sử dụng của từng dịch vụ:
  * Amazon S3
  * Amazon Glacier
  * AWS Storage Gateway
  * Amazon FSx

* Hoàn thành các bài thực hành của Module 04:
  * Di trú máy ảo lên AWS
  * Triển khai Amazon FSx

* Hoàn thiện tài liệu phân tích và thiết kế hệ thống:
  * Use Case Diagram
  * Entity Relationship Diagram (ERD)
  * Database Schema

* Xây dựng thành công cấu trúc cơ sở dữ liệu và các Models ban đầu cho hệ thống Quản lý thư viện.

* Hoàn thành các chức năng Backend nền tảng:
  * Quản lý sách
  * Quản lý thể loại
  * Quản lý nhà xuất bản

* Hoàn thành Sprint đầu tiên, tạo nền tảng để tiếp tục phát triển các chức năng nghiệp vụ và tích hợp Frontend trong tuần tiếp theo.
