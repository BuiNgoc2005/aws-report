### Kết quả đạt được tuần 3:

* Biết cách cài đặt và sử dụng AWS CLI để quản lý tài nguyên AWS bằng dòng lệnh.

* Hiểu và thực hành các dịch vụ AWS phục vụ triển khai ứng dụng:
  * AWS CLI
  * Amazon S3
  * Amazon RDS
  * Amazon CloudWatch

* Khởi tạo thành công dự án Website Quản lý thư viện:
  * GitHub Repository
  * Django Project
  * Docker và Docker Compose
  * PostgreSQL
  * Cấu trúc thư mục và các ứng dụng ban đầu

* Hoàn thành phân tích nghiệp vụ của hệ thống:
  * Quản lý sách
  * Quản lý độc giả
  * Quản lý mượn/trả sách
  * Quản lý tài khoản

* Xác định các Actor và hoàn thiện tài liệu SRS, tạo nền tảng để bắt đầu phát triển các chức năng của hệ thống từ tuần 4.
