### Kết quả đạt được tuần 5:

* Hiểu được các dịch vụ bảo mật và quản lý định danh trên AWS:
  * AWS IAM
  * AWS Organizations
  * AWS KMS
  * AWS Security Hub
  * AWS CloudTrail

* Hoàn thành các bài thực hành của Module 05:
  * Kích hoạt AWS Security Hub
  * Tạo và quản lý IAM Policy
  * Chuyển đổi Role (Switch Role)
  * Quản lý tài nguyên bằng Resource Tags

* Hoàn thành việc phân tích dữ liệu của hệ thống Quản lý thư viện.

* Thiết kế và hoàn thiện sơ đồ Entity Relationship Diagram (ERD), mô tả đầy đủ các thực thể, thuộc tính và mối quan hệ trong cơ sở dữ liệu.

* Hoàn thiện Database Schema, làm cơ sở cho việc xây dựng cơ sở dữ liệu và phát triển các chức năng của hệ thống trong các tuần tiếp theo.
