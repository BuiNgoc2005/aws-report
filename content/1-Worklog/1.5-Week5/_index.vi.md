### Kết quả đạt được tuần 5:

* Hiểu được các dịch vụ bảo mật trên AWS:
  * AWS IAM
  * AWS Organizations
  * AWS KMS
  * AWS Security Hub

* Hoàn thành các bài thực hành của Module 05:
  * Quản lý IAM User, Group và Role
  * Xây dựng IAM Policy
  * Tìm hiểu AWS Security Hub
  * Quản lý tài nguyên bằng Resource Tags

* Hoàn thiện các chức năng Backend quan trọng của hệ thống:
  * Quản lý sách
  * Quản lý thể loại
  * Quản lý nhà xuất bản
  * Quản lý độc giả
  * Quản lý tài khoản người dùng

* Xây dựng RESTful API phục vụ quá trình tích hợp giữa Backend và Frontend.

* Hoàn thành kiểm thử các API chính, đảm bảo các chức năng hoạt động ổn định trước khi tích hợp giao diện.

* Hoàn thành Sprint thứ hai và sẵn sàng bước sang giai đoạn hoàn thiện toàn bộ chức năng của hệ thống.
